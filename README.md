## What it does

`main.py` (Python 3.13 standard library only) writes one original single-line joke, at most 200 characters, to `entry.txt` in the output directory (`OUTPUT_DIR`, default `/output`).

## Run it

```sh
python3 main.py
```

## The joke

> I joined a 'quick sync' about an email and left an hour later with a follow-up meeting and still no answer.
